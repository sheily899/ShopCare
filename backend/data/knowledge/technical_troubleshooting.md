# 技术故障排查指引

## 常见错误码

### 401：认证失败

确认用户名和密码是否正确，检查验证码或登录授权是否过期；仍无法登录时，可尝试密码重置。不要在客服对话中提供密码或短信验证码。

### 403：权限不足

确认账户没有被冻结，检查当前账号是否具备访问权限，以及网络是否处于允许的 IP 范围。权限问题需要后台或人工客服核验，ShopCare 不修改权限。

### 404：页面或资源不存在

确认访问地址没有拼写错误，尝试从产品首页重新进入，并检查页面是否已下线或链接是否过期。若同一账号持续出现 404，请记录页面地址、发生时间和设备环境后提交人工核验。

### 500：服务器错误

500 通常表示服务端异常。建议稍后重试、检查是否为短时网络波动；若持续出现，请记录错误码、发生时间和操作步骤，交由技术支持进一步排查。ShopCare 不读取服务端日志，也不承诺故障已修复。

## 网络与应用排查

页面加载慢或连接超时时，可检查网络连接、切换 Wi-Fi 和移动数据、清理应用或浏览器缓存，并尝试使用其他浏览器。应用频繁崩溃时，可确认存储空间、重启应用并升级到可用版本；以上步骤无效时应保留错误信息并请求人工协助。
